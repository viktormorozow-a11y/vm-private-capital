VM Private Capital v8.0.3 — Mobile App / PWA

Для обновления загрузите ВСЁ содержимое этой папки на HTTPS-хостинг, сохранив структуру:
  index.html
  manifest.webmanifest
  sw.js
  icons/
    vm-private-capital-180.png
    vm-private-capital-192.png
    vm-private-capital-512.png

index.html — основной файл сайта.
VM_Private_Capital_v8.0.3.html — идентичная архивная копия с номером релиза.

Исправления v8.0.3:
- Мобильные графики: один тап фиксирует tooltip; после отпускания пальца он не исчезает. Тап вне графика закрывает его.
- Отключены выделение canvas, iOS long-press callout и контекстное меню на графиках.
- Подписи X-оси на телефоне сокращены и прорежены; легенда вынесена из canvas в адаптивный блок.
- Облачное сохранение больше не теряет второе изменение, если первое сохранение ещё идёт: новое состояние ставится в очередь.
- BTC-кошельки синхронизируются последовательно, чтобы два кошелька не перезаписывали состояние друг друга.
- После перезагрузки текущая стоимость привязанного BTC-кошелька берётся из уже сохранённых btcWalletBlockchainBalance × btcWalletCurrentRate, если эти данные свежее последней snapshot. Поэтому сумма не откатывается к старой оценке до следующего API-запроса.
- Mempool.space и CoinGecko получили повторные попытки при временных 5xx/429/сетевых ошибках.
- Исторические значения по датам по-прежнему берутся из snapshots; текущий cache-fallback не переписывает прошлую историю.

Важно:
- PWA-установка на iPhone работает только после публикации через HTTPS.
- Service Worker не кэширует Supabase/Auth/API-запросы, HTML, экспорты или финансовые ответы.
- Для корректного обновления PWA заменяйте весь пакет, а не только index.html.
