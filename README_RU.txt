VM Private Capital v8.0.2 — Mobile App / PWA

Для публикации загрузите ВСЮ папку на HTTPS-хостинг, сохранив структуру:
  index.html
  manifest.webmanifest
  sw.js
  icons/
    vm-private-capital-180.png
    vm-private-capital-192.png
    vm-private-capital-512.png

index.html — готовый основной файл сайта.
VM_Private_Capital_v8.0.2.html — идентичная версия с номером релиза для архива.

Что нового в v8.0.2:
- При входе BTC-кошельки автоматически подтягивают новые blockchain-транзакции, как раньше.
- Если сайт не открывался несколько дней, приложение восстанавливает пропущенные дневные точки BTC/EUR по исторической цене.
- Баланс BTC для каждого дня рассчитывается с учётом транзакций, которые уже произошли к концу этого дня.
- Входящие BTC остаются Mining; исходящие — transfer_out.
- На один кошелёк создаётся не более одной автоматической точки за день; повторный вход обновляет её вместо создания дубля.
- Если историческая цена временно недоступна, курсор не перескакивает через этот день: следующий вход повторит попытку.
- Ручные оценки не удаляются и не перезаписываются автоматикой.

Важно:
- PWA-установка на iPhone работает только после публикации через HTTPS.
- Service Worker не кэширует Supabase/Auth/API-запросы, HTML, экспорты или финансовые ответы.
- Финансовые данные продолжают использовать существующее хранение приложения/Supabase; PWA не добавляет отдельный финансовый офлайн-кэш.
- Desktop/iPad используют существующий desktop UI; отдельный Mobile UI включается на phone-class touch devices.
